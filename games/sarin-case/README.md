# 特別捜査本部 — 地下鉄サリン事件・捜査シミュレーション

## 起動方法

[`index.html`](./index.html) をブラウザで開くと遊べます。HTML単体で動作し、外部ライブラリや画像ファイルは不要です。

## ゲームの目的

12回の行動以内に史実資料4点（複数路線の被害記録、鑑定報告、施設捜索資料、先行事件の捜査資料）を集め、取調べで矛盾を立証してゲーム内の架空の関係者から自供を得ます。

質問、資料調査、証拠提示、問い詰めはいずれも1ターンを消費します。正しい証拠を提示すると動揺ゲージが上がり、動揺100で問い詰めると自供します。誤った証拠提示や早すぎる追及で反発ゲージが100になると、その人物は黙秘します。

## 史実とフィクションの区別

事件の概要と捜査の節目は、警察白書の公開資料を参照しています。一方、登場人物A〜C、取調べの会話、自供、供述照合メモ、指示系統の仮説図はすべてゲーム用の架空設定であり、実在の人物の発言や実際の供述記録ではありません。

参考資料：
- [警察庁『平成8年 警察白書』地下鉄サリン事件](https://www.npa.go.jp/hakusyo/h08/h080102.html)
- [警察庁『平成8年 警察白書』事件捜査と市民の保護](https://www.npa.go.jp/hakusyo/h08/h080103.html)

## 操作

1. 「資料を調べる」で証拠を調査する。
2. 「取調室」で人物と質問を選ぶ。
3. 証言が出たら、適切な資料を提示して矛盾を立証する。
4. 動揺が100になったら「問い詰める」を選ぶ。
5. 12ターン以内に主要資料4点と自供をそろえる。

この作品は歴史的事件を扱う調査シミュレーションです。被害者や遺族の苦痛を軽視しないよう、派手な演出よりも資料の照合と捜査判断を中心にしています。
